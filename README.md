# Lecture-Voice-to-Notes-Generator-using-Generative-AI

An AI-powered Streamlit application that converts lecture audio into **structured study materials** including:

-  Time-synced transcripts  
-  Summary notes  
-  Interactive quizzes  
-  Flashcards  

Built using **Google Gemini API**, **Streamlit**, and **Pydantic**, this tool helps students transform lectures into effective learning resources.

---

##  Features

-  **Audio Transcription with Timestamps**  
  Converts lecture audio into a detailed transcript with `[HH:MM:SS]` time markers.

-  **Smart Summary Notes**  
  Generates clean, structured notes using Markdown formatting.

-  **Interactive Quiz**  
  - 5 MCQs generated from lecture content  
  - Instant feedback on answers  

-  **Flashcards Generator**  
  - 10 key concepts with definitions  
  - Flip-card UI for active recall learning  

-  **End-to-End Automation**  
  Upload audio → Get all study materials instantly  

---

##  Tech Stack

- **Frontend:** Streamlit  
- **Backend:** Python  
- **AI Model:** Google Gemini (`gemini-2.5-flash`)  
- **Data Validation:** Pydantic  
- **Other Libraries:** JSON, OS, Typing
